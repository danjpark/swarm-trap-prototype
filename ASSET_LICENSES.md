# Asset provenance

All visible artwork is original procedural geometry created for this prototype:
Canvas creatures, terrain, rotating fire arms, conveyors, platforms, spawn and
exit markers; inline SVG toolbox icons; and the SVG favicon.

There are no downloaded game sprites, stock images, third-party fonts, audio,
or runtime asset services. Fonts use the local system font stack. The Vite
template's demo graphics have been removed.

If third-party assets are introduced later, record their author, original URL,
license, modifications, and attribution requirements here before publishing.
